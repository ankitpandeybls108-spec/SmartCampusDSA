# Algorithms Used

## Campus navigation

**BFS** explores the graph level by level and is useful for unweighted hop-based traversal.

**DFS** explores one branch deeply before backtracking.

**Dijkstra** computes shortest weighted paths because all campus road weights are non-negative.

## Network optimization

**Prim** grows a minimum spanning tree from a chosen campus location.

**Kruskal** sorts all roads by weight and uses a disjoint-set structure to avoid cycles.

## Scheduling

**Activity Selection** sorts activities by finishing time and greedily chooses the next compatible activity.

## Resource allocation

**0/1 Knapsack** uses dynamic programming to maximize total resource value under a capacity limit.

## Searching and sorting

The project also includes linear search, binary search, merge sort, and quick sort.
